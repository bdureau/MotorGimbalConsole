Bear Altimeter Motor Gimbal Console Help

This guide explains how to use your Android Bear Altimeter Motor Gimbal console. The Android console is a convenient field tool to configure PID stabilization, review flight curves, and monitor real-time telemetry directly at the launch pad.

Initial Setup & Bluetooth Pairing

  1. Firmware Verification: Ensure your gimbal flight computer has a compatible firmware version installed.
  2. Module Connection: Verify that the wireless Bluetooth module (HC-05, HC-06, or HC-07) is securely connected to the gimbal controller.
  3. Device Pairing: Open your Android device Settings > Bluetooth and search for available devices. Pair with the module (the default PIN is usually 1234 or 0000).
⚠ CAUTION
We strongly recommend renaming each paired Bluetooth module in your Android Bluetooth settings (e.g., "Rocket-Gimbal-1") to ensure you connect to the intended rocket on the launch rail.
  1. Power On: Turn on the gimbal board and keep the rocket vertical and motionless until the IMU calibration and gyro initialization complete.
  2. Connect: Open the app, tap Connect/Disconnect, and select your paired module. The connection status indicator will confirm a successful link.

Using the Gimbal Console

Main Dashboard Actions

[Gimbal Config]

Reads onboard configuration from the flight computer and allows you to tune servo limits, PID parameters, and sensor orientations.

[Flights]

Downloads flight logs from flash memory. Allows plotting altitude curves, acceleration profiles, and replay of servo actuation during motor burn.

[Telemetry]

Live flight telemetry monitor with optional audio/voice annunciations for apogee, altitude, and trajectory status.

[Reset]

Restores gimbal configuration to factory defaults, and allows erasing flight logs or clearing only the most recent flight.

[Status]

Displays real-time diagnostic telemetry, battery voltage, servo center positions, and sensor health checks.

[Flash Firmware]

Flashes updated firmware onto the gimbal controller over USB or serial bootloader.

[About]

Displays application version, build info, and developer credits.

[Connect / Disconnect]

Establishes or terminates the Bluetooth / USB serial link with the gimbal.

Application Options Menu

From the action bar menu, you can access this help documentation, view the About dialog, configure connection module parameters (Bluetooth, 3DR, LoRa), or customize UI preferences.
