Configuración de la Aplicación Motor Gimbal

Esta guía detalla los ajustes globales, la apariencia y el comportamiento de la consola Android Bear Altimeter Motor Gimbal.

Nota: Los parámetros modificados aquí afectan exclusivamente a la aplicación móvil y sus interfaces de enlace, no a los parámetros internos de control del gimbal.

Comunicación y tipo de enlace

Interfaz predeterminada: Seleccione el puerto de enlace preferido: Bluetooth inalámbrico (RFCOMM) o cable serie USB-OTG.

Velocidad en baudios (Baud Rate): Configure la velocidad de comunicación serie (habitualmente 38400 o 57600 baudios según el módulo transceptor).

Módulos de telemetría: Opciones para transceptores de largo alcance como módulos 3DR Radio, LoRa E32 o LoRa E220.

Visualización y unidades

Sistema de unidades: Alterne entre el sistema métrico (metros, m/s, °C) y el sistema imperial (pies, ft/s, °F) para indicadores e historial gráfico de vuelo.

Tema y apariencia: Personalice colores, active el modo oscuro o de alto contraste para visibilidad bajo luz solar intensa y ajuste el suavizado de curvas.

Telemetría por voz y alarmas sonoras

Locución por voz (TTS): Habilite o deshabilite las alertas habladas durante el vuelo (altitud instantánea, cruce del apogeo y aviso de batería baja).

Frecuencia de locución: Defina el intervalo de actualización de voz (por ejemplo, cada 50 metros de ascenso o cada segundo).
