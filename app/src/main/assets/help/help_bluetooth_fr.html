Sélection du module Bluetooth

Cet écran vous permet de choisir le module Bluetooth cible lors de la première connexion à votre Gimbal Bear Altimeter ou lorsque vous souhaitez changer de fusée sur le terrain.

Procédure d'appairage et de sélection

  1. Appairage système Android : Avant toute sélection dans l'application, vous devez obligatoirement appairer l'émetteur-récepteur Bluetooth (HC-05, HC-06 ou HC-07) dans le menu Paramètres > Bluetooth de votre appareil Android. Le code d'association d'usine est généralement 1234 ou 0000.
  2. Sélection du module : Dans la liste des périphériques associés affichée à l'écran, sélectionnez le module qui équipe votre gimbal actif.
  3. Établissement de la liaison : Revenez à l'écran principal et relancez la connexion. Si vous avez sélectionné le mauvais module ou si le gimbal n'est pas sous tension, la synchronisation échouera.
⚠ CONSEIL IMPORTANT
Prenez soin de renommer clairement chaque adaptateur Bluetooth dans les paramètres Android de votre téléphone (par exemple : « Fusée-Gimbal-1 », « Fusée-Gimbal-2 »). Vous éviterez ainsi d'envoyer des paramètres ou des commandes vers un autre modèle sur la rampe de lancement.

Dépannage de la communication

  • Vérifiez le voyant d'état (LED) du module Bluetooth : clignotement rapide en attente de liaison, fixe une fois connecté.
  • Assurez-vous que la batterie de l'ordinateur de vol est branchée et fournit une tension suffisante au récepteur.
  • Si le module n'apparaît pas dans la liste, vérifiez que les autorisations Bluetooth / Appareils à proximité sont accordées à l'application.
