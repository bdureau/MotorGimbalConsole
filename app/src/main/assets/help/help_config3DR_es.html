Configuración del módulo de telemetría 3DR

Para lograr enlaces de telemetría de largo alcance, se sustituye el enlace Bluetooth por un conjunto de radiomódems 3DR.

Alimentación eléctrica: Verifique que la batería de su dispositivo Android entregue suficiente corriente a través de USB-OTG para alimentar el módulo terrestre. Con módulos de alta potencia (500mW o 1W) se recomienda utilizar un concentrador USB alimentado o una batería externa.

Material necesario para la configuración

  • Un cable convertidor USB a TTL serie.
  • Un adaptador USB-OTG compatible con su teléfono o tableta (USB-C o Micro-USB).
  • Un adaptador JST y cables de interconexión JST.

Compatibilidad de velocidad (Baud Rate)

La mayoría de los módulos 3DR vienen configurados de fábrica a 57600 baudios. Sin embargo, la placa controladora del Gimbal funciona por defecto a 38400 baudios. Es indispensable ajustar la velocidad serie de ambos radiomódems para que coincida con la controladora de vuelo.

⚠ ATENCIÓN CRÍTICA
No desconecte nunca el módulo durante la lectura o escritura de datos para evitar la corrupción de la memoria EEPROM.

Pasos de configuración

  1. Conexión: Conecte el módulo 3DR al dispositivo Android mediante el cable USB a TTL y el adaptador OTG.
  2. Leer parámetros: Pulse en [Retrieve cfg]. La aplicación probará sucesivamente distintas velocidades en baudios hasta sincronizar con el módulo y cargar sus parámetros actuales.
  3. Modificar parámetros: Ajuste los valores deseados (velocidad en baudios compatible con el Gimbal, canales de frecuencia e ID de red).
  4. Guardar configuración: Pulse en [Save cfg] para grabar los datos en el módulo. Ante cualquier error de comunicación, el proceso de guardado se cancelará.
Módulos emparejados: Los módulos 3DR trabajan por parejas (emisor a bordo del cohete y receptor en tierra). Repita esta operación con ambos dispositivos asegurándose de que compartan el mismo Net ID, frecuencias y velocidad en baudios.
