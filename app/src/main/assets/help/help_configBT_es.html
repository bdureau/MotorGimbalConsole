Configuración del módulo Bluetooth

Para comunicar su altímetro o controladora de gimbal con el teléfono Android, el módulo Bluetooth debe estar configurado a la misma velocidad serie que la electrónica de a bordo.

Esta herramienta permite programar módulos Bluetooth estándar como HC-05, HC-06 o equivalentes.

Herramientas de programación necesarias

  • Un cable adaptador USB a TTL serie.
  • Un adaptador USB-OTG compatible con su teléfono o tableta (USB-C o Micro-USB).
  • Un adaptador JST y cables de interconexión JST.

Ajuste de la velocidad en baudios (Baud Rate)

La mayoría de los módulos Bluetooth vienen configurados de fábrica a 9600 baudios. Sin embargo, la controladora del altímetro y gimbal opera por defecto a 38400 baudios. Es necesario reconfigurar la velocidad UART del módulo a 38400 baudios para garantizar la comunicación.

⚠ PRECAUCIÓN IMPORTANTE
No desconecte nunca el módulo durante la lectura o escritura de parámetros para evitar dañar los registros de memoria interna.

Pasos de configuración

  1. Conexión: Conecte el módulo Bluetooth al dispositivo Android utilizando el cable USB a TTL y el adaptador OTG.
  2. Selección de módulo: Elija el modelo de módulo correspondiente en la lista desplegable (ej. HC-05 o HC-06). En caso de duda, mantenga la opción predeterminada.
  3. Leer parámetros: Pulse en [Retrieve cfg]. La aplicación iniciará la comunicación a 38400 baudios y probará otras velocidades si fuera necesario hasta recibir respuesta válida del módulo.
  4. Modificar parámetros: Cambie el nombre del dispositivo (ej. "Cohete-Gimbal-1"), ajuste la velocidad a 38400 baudios y configure el código PIN si lo desea (por defecto: 1234).
  5. Guardar configuración: Pulse en [Save cfg] para grabar los datos en el módulo. Si surge algún error durante el proceso, el guardado se abortará de forma segura.
Nota: Deberá repetir este procedimiento con cada módulo Bluetooth que utilice en sus cohetes.
