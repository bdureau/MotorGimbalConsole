Configuration d'un module Bluetooth

Pour connecter votre altimètre ou votre gimbal moteur à votre téléphone Android via Bluetooth, le module sans fil doit impérativement être configuré à la même vitesse série que la carte de vol.

Cet utilitaire prend en charge les modules Bluetooth courants tels que les HC-05, HC-06 et modèles compatibles.

Matériel requis pour la programmation

  • Un câble adaptateur USB vers série TTL.
  • Un adaptateur USB-OTG adapté à votre smartphone ou tablette (USB-C ou Micro-USB).
  • Un adaptateur JST et des cordons de liaison JST.

Harmonisation de la vitesse (Baud Rate)

Ces modules sont généralement configurés d'usine à 9600 bauds. Cependant, l'ordinateur de vol de votre altimètre/gimbal fonctionne par défaut à 38400 bauds. Il est donc nécessaire de modifier la vitesse interne du module pour qu'elle soit de 38400 bauds.

⚠ AVERTISSEMENT IMPORTANT
Ne débranchez jamais le module pendant la lecture ou l'écriture des paramètres afin de ne pas corrompre ses registres AT ou sa mémoire interne.

Procédure de configuration

  1. Raccordement matériel : Reliez le module Bluetooth à votre appareil Android en utilisant le câble USB-TTL et l'adaptateur OTG.
  2. Choix du modèle : Sélectionnez le type de votre module dans la liste déroulante (par exemple HC-05 ou HC-06). Si vous ne connaissez pas le modèle exact, laissez l'option par défaut.
  3. Lecture de la configuration : Touchez [Charger cfg]. L'application testera la communication à 38400 bauds puis balayera les autres vitesses usuelles (9600, 19200, 57600, 115200) jusqu'à obtenir une réponse valide.
  4. Modification des paramètres : Renommez le module (par exemple : « Fusée-Gimbal-1 »), ajustez la vitesse à 38400 bauds et modifiez si nécessaire le code PIN d'association (par défaut : 1234).
  5. Sauvegarde : Touchez [Sauver cfg] pour enregistrer les paramètres dans le module. En cas d'erreur de communication, l'opération est automatiquement interrompue.
Remarque : Répétez cette même procédure pour chaque module Bluetooth que vous prévoyez d'utiliser sur vos fusées.
