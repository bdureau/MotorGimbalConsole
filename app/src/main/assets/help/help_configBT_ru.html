Настройка модуля Bluetooth

Для надежного обмена данными между бортовым высотомером/подвесом и приложением на смартфоне скорость последовательного интерфейса модуля Bluetooth должна строго совпадать со скоростью полетного контроллера.

Данный инструмент предназначен для прошивки и конфигурирования модулей HC-05, HC-06 и совместимых с ними адаптеров.

Оборудование для программирования

  • Кабель-переходник USB-TTL.
  • Переходник USB-OTG под разъем вашего мобильного устройства (USB-C или Micro-USB).
  • Переходная колодка JST и соединительные провода.

Согласование скорости обмена (Baud Rate)

Заводская скорость UART большинства модулей Bluetooth составляет 9600 бод. Контроллер высотомера и подвеса Gimbal по умолчанию работает на скорости 38400 бод. Необходимо перенастроить модуль на скорость 38400 бод.

⚠ ВНИМАНИЕ
Категорически запрещается отключать модуль от кабеля во время считывания или записи данных, чтобы не повредить регистры AT-команд.

Порядок действий

  1. Подключение: Подключите модуль Bluetooth к Android-устройству через USB-TTL адаптер и кабель OTG.
  2. Выбор модели: Укажите тип используемого модуля в списке (HC-05, HC-06). Если точная модель неизвестна, оставьте вариант по умолчанию.
  3. Считывание параметров: Нажмите [Retrieve cfg]. Приложение выполнит опрос на скорости 38400 бод, а при необходимости переберет остальные скорости до установления связи с адаптером.
  4. Изменение настроек: Задайте понятное имя модуля (например, «Rocket-Gimbal-1»), установите скорость 38400 бод и при необходимости измените PIN-код (по умолчанию: 1234).
  5. Запись конфигурации: Нажмите [Save cfg] для сохранения параметров в энергонезависимой памяти. При возникновении ошибки запись будет отменена.
Примечание: Повторите эту процедуру для каждого Bluetooth-модуля, используемого в ракетах.
