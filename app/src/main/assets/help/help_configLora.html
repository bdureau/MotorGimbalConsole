eByte LoRa E220 Module Configuration

To establish long-range downlink rocket telemetry beyond Bluetooth reach, replace the wireless Bluetooth module with an eByte LoRa E220 transceiver pair.

Tested & Supported Modules

  • E220-400T30D / E220-400T30S
  • E220-900T30D / E220-900T30S
  • E220-400T22D / E220-900T22S

Power Requirement: Ensure your Android mobile device provides adequate power via USB-OTG. High-power 30dBm (1 Watt) LoRa transmitters draw significant current and require an external battery or powered USB hub to prevent brownouts.

Required Programming Hardware

  • A USB-to-TTL serial adapter cable.
  • A USB-OTG adapter suitable for your phone or tablet (USB-C or Micro-USB).
  • A JST adapter and matching JST wiring harness.
⚠ CRITICAL: HARDWARE JUMPERS (M0 / M1)
To enter configuration mode, install both jumpers (M0 and M1 set to HIGH). After saving the parameters, you must remove both jumpers to return the module to standard transmission mode.

Baud Rate Alignment

While the internal AT configuration interface communicates at 9600 baud, factory module serial ports often default to 57600 baud. The rocket flight computer communicates by default at 38400 baud. You must configure the module's operating UART speed to 38400 baud.

⚠ CAUTION
Do not disconnect or power off the module during read or write operations.

Configuration Steps

  1. Hardware Setup: Place both jumpers on the module. Connect it to your Android device using the USB-TTL cable and OTG adapter.
  2. Read Parameters: Tap [Retrieve cfg]. The app connects at 9600 baud and displays current module registers.
  3. Configure Settings: Set the serial UART baud rate to 38400 baud. Match the RF frequency channel, Air Data Rate, Net ID, and encryption key across both units.
  4. Save Settings: Tap [Save cfg] to write parameters into non-volatile memory. If an error occurs, writing aborts automatically.
  5. Exit Configuration Mode: Unplug the module and remove both jumpers before connecting to the rocket or ground station.
Paired Setup: LoRa radios operate as transmitter and receiver pairs. Repeat the configuration for both modules. Note: LoRa telemetry modules currently do not support ESP32 boards.
