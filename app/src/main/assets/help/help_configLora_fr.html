Configuration d'un module eByte LoRa E220

Pour effectuer de la télémétrie longue portée hors de portée du Bluetooth, remplacez votre adaptateur Bluetooth par une paire d'émetteurs-récepteurs eByte LoRa E220.

Modules testés et compatibles

  • E220-400T30D / E220-400T30S
  • E220-900T30D / E220-900T30S
  • E220-400T22D / E220-900T22S

Alimentation électrique : Assurez-vous que le port USB-OTG de votre appareil Android fournit un courant suffisant. Les modules puissants de 30 dBm (1 Watt) consomment un courant important et nécessitent une batterie externe ou un hub USB alimenté pour éviter toute coupure.

Matériel requis pour la programmation

  • Un câble adaptateur USB vers série TTL.
  • Un adaptateur USB-OTG adapté à votre appareil (USB-C ou Micro-USB).
  • Un adaptateur JST et des câbles de raccordement JST.
⚠ CRITIQUE : CAVALIERS DE MODE (M0 / M1)
Pour basculer le module en mode configuration, installez les 2 cavaliers (M0 et M1 à l'état haut). Une fois la programmation terminée, vous devez impérativement retirer les 2 cavaliers pour repasser en mode de transmission radio standard.

Harmonisation de la vitesse (Baud Rate)

La lecture des commandes de configuration s'effectue à 9600 bauds, mais les modules sont souvent paramétrés en usine à 57600 bauds. L'ordinateur de vol du gimbal fonctionne par défaut à 38400 bauds. Vous devez configurer la vitesse UART de fonctionnement à 38400 bauds.

⚠ AVERTISSEMENT
Ne débranchez jamais le module pendant la lecture ou l'écriture des paramètres.

Procédure de configuration

  1. Préparation : Placez les 2 cavaliers sur le module. Raccordez-le à votre appareil Android via le câble USB-TTL et l'adaptateur OTG.
  2. Lecture de la configuration : Touchez [Charger cfg]. L'application se connecte à 9600 bauds et charge les paramètres du module.
  3. Modification des paramètres : Réglez la vitesse sur 38400 bauds. Assurez-vous que le canal de fréquence, la vitesse radio (Air Data Rate) et la clé de chiffrement soient strictement identiques sur les deux modules.
  4. Sauvegarde : Touchez [Sauver cfg] pour enregistrer. En cas d'erreur, l'écriture est immédiatement annulée.
  5. Sortie du mode configuration : Débranchez le module et enlevez les 2 cavaliers avant de l'installer sur la fusée ou la station sol.
Fonctionnement en paire : Les modules LoRa s'utilisent obligatoirement par deux (émetteur et récepteur). Répétez ces étapes pour chacun des deux modules. Remarque : les modules LoRa ne sont actuellement pas compatibles avec les cartes ESP32.
