Archivo de ayuda del banco de pruebas

Esta es una ayuda rápida para usar su aplicación Test Stand. La aplicación Test Stand es una forma muy práctica de registrar las curvas de empuje de sus motores directamente en el campo.

Configuración inicial y emparejamiento Bluetooth

  1. Compatibilidad del firmware: Asegúrese de que su placa del banco de pruebas es compatible (es decir, de que se ha cargado el firmware correcto).
  2. Conexión del módulo: Asegúrese de que el módulo Bluetooth está conectado a la placa del banco de pruebas.
  3. Emparejamiento en el sistema: Vaya a los ajustes de su dispositivo Android, abra la configuración de Bluetooth y busque el módulo HC-05, HC-06 u otro módulo Bluetooth. Introduzca el código PIN de emparejamiento (por defecto 1234).
⚠ PRECAUCIÓN
Ponga un nombre claro a cada dispositivo Bluetooth emparejado en su teléfono para estar seguro de configurar el banco de pruebas correcto.
  1. Encendido: Encienda el banco de pruebas y espere hasta que deje de pitar.
  2. Conexión: Inicie la aplicación en su dispositivo Android, pulse «Mostrar dispositivos vinculados» y seleccione su módulo HC-05 o HC-06. La consola intentará conectarse.

Una vez conectado, puede usar la aplicación para configurar su banco de pruebas o leer las curvas de empuje registradas. Si no consigue conectarse, compruebe que la placa está encendida y que ha seleccionado el adaptador Bluetooth correcto.

Uso de la aplicación Test Stand

Acciones de la pantalla principal

[Ajustes del Banco de Pruebas]

Lee la configuración actual del banco de pruebas y le permite modificarla.

[Leer Curvas de Empuje]

Lee de la memoria todas las curvas de empuje registradas y las muestra como gráficos interactivos.

[Telemetría]

Abre la telemetría en tiempo real enviada por el banco de pruebas.

[Restablecer Ajustes]

Restaura los parámetros de fábrica. También permite borrar todas las curvas de empuje almacenadas.

[Estado]

Abre la pantalla de diagnóstico del hardware, que muestra el estado de los sensores, la tensión de la batería y el estado de la placa.

[Actualizar Firmware]

Permite actualizar el firmware de la placa directamente mediante un cable USB.

[Conectar / Desconectar]

Establece o interrumpe la comunicación con el banco de pruebas.

Menú de la pantalla principal

Desde el menú de opciones puede abrir esta guía de ayuda, acceder a la pantalla «Acerca de», que muestra la información de la versión, y personalizar la apariencia de la aplicación.

Hardware compatible

Esta aplicación es compatible con las siguientes placas de banco de pruebas:

• Banco de pruebas ATmega328

Es el prototipo original de banco de pruebas, que realicé con un ATmega328.

• Banco de pruebas STM32 (versión 1)

Es el primer banco de pruebas de serie, con una placa STM32. Solo tiene una entrada para el sensor de fuerza (galga), por lo que únicamente puede medir el empuje.

• Banco de pruebas STM32 (versión 2)

Es la segunda versión del banco de pruebas, que también usa una placa STM32. Tiene una entrada para el sensor de fuerza para medir el empuje y 2 entradas analógicas para medir la presión dentro de la carcasa del motor.

• Banco de pruebas ESP32 (versión 3)
