Fichier d'aide pour Banc de Test Moteur

Ceci est une aide rapide pour utiliser votre application Test Stand. L'application Test Stand est un moyen très pratique d'enregistrer les courbes de poussée de vos moteurs directement sur le terrain.

Configuration initiale et appairage Bluetooth

  1. Compatibilité du firmware : Assurez-vous que votre carte de banc de test est compatible (c'est-à-dire que le bon firmware y a été chargé).
  2. Connexion du module : Vérifiez que le module Bluetooth est bien raccordé à la carte du banc de test.
  3. Appairage système : Ouvrez les paramètres de votre appareil Android, puis les réglages Bluetooth, et recherchez le module HC-05, HC-06 ou tout autre module Bluetooth. Saisissez le code PIN d'appairage (par défaut 1234).
⚠ ATTENTION
Donnez un nom explicite à chaque appareil Bluetooth appairé sur votre téléphone, afin d'être certain de configurer le bon banc de test.
  1. Mise sous tension : Allumez le banc de test et attendez qu'il cesse d'émettre des bips.
  2. Connexion : Lancez l'application sur votre appareil Android, touchez « Montrer les périphériques » et sélectionnez votre module HC-05 ou HC-06. La console tente alors de se connecter.

Une fois connecté, vous pouvez utiliser l'application pour configurer votre banc de test ou lire les courbes de poussée enregistrées. Si la connexion échoue, vérifiez que la carte est bien alimentée et que le bon adaptateur Bluetooth est sélectionné.

Utilisation de l'application Test Stand

Commandes de l'écran principal

[Config Banc de Test Moteur]

Lit la configuration actuelle du banc de test et vous permet de la modifier.

[Chargement Courbes de Poussées]

Lit toutes les courbes de poussée enregistrées en mémoire et les affiche sous forme de graphiques interactifs.

[Télémétrie]

Ouvre la télémétrie en temps réel transmise par le banc de test.

[Réinit Config]

Restaure les paramètres d'usine. Permet aussi d'effacer toutes les courbes de poussée enregistrées.

[État]

Ouvre l'écran de diagnostic matériel, qui affiche l'état des capteurs, la tension de la batterie et l'état de la carte.

[Flash Firmware]

Permet de mettre à jour le firmware de la carte directement par câble USB.

[Connexion / Déconnexion]

Établit ou interrompt la communication avec le banc de test.

Menu de l'écran principal

Depuis le menu d'options, vous pouvez ouvrir ce guide d'aide, accéder à l'écran « À propos » qui affiche les informations de version, et personnaliser l'apparence de l'application.

Matériel pris en charge

Cette application prend en charge les cartes de banc de test suivantes :

• Banc de test ATmega328

Il s'agit du prototype de banc de test d'origine, que j'ai réalisé avec un ATmega328.

• Banc de test STM32 (version 1)

Il s'agit du premier banc de test de série, équipé d'une carte STM32. Il n'a qu'une seule entrée pour le capteur de force (jauge) : il ne peut donc mesurer que la poussée.

• Banc de test STM32 (version 2)

Il s'agit de la deuxième version du banc de test, elle aussi équipée d'une carte STM32. Elle dispose d'une entrée pour le capteur de force afin de mesurer la poussée, et de 2 entrées analogiques pour mesurer la pression à l'intérieur du corps du moteur.

• Banc de test ESP32 (version 3)

Il s'agit de la troisième version du banc de test, qui utilise une puce ESP32. Elle dispose d'une entrée pour le capteur de force afin de mesurer la poussée, et de 2 entrées analogiques pour mesurer la pression à l'intérieur du corps du moteur.
